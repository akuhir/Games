# Scripts

CarController.cs — physics, acceleration, braking, steering and speed limiting.
MobileControls.cs — connects UI pointer buttons to the car.
FollowCamera.cs — third-person camera.
RaceManager.cs — ordered checkpoints, laps, timer and finish event.
Checkpoint.cs — trigger checkpoint logic.
RaceHUD.cs — lap/time display and finish panel.
FinishScreen.cs — restart button.
